================================================================================
DESIGN PATTERNS
================================================================================

Registry Pattern:
  ✅ Centralized registration
  ✅ Single source of truth
  ✅ Runtime registration support
  ✅ Type-safe (extends base class)
  ✅ Singleton global instance

Strategy Pattern:
  ✅ Each connector is a strategy
  ✅ Pluggable implementations
  ✅ Different behaviors, same interface
  ✅ Easy to add new connectors

Template Method Pattern:
  ✅ Base class defines structure
  ✅ Subclasses implement specifics
  ✅ Common patterns in base or generics
  ✅ Platform-specific overrides in subclasses

Dependency Injection:
  ✅ set_page() injects Page context
  ✅ No hardcoded page access
  ✅ Testable (can inject mock pages)
  ✅ Flexible for different use cases
